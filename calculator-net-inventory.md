## Take on this for PaisaCalc

Only the **Financial** category overlaps with PaisaCalc's actual positioning ("Indian personal-finance calculators"). Within it, every one of the 71 items has now been triaged:

- **54 of the 71 items map to a live calculator** (marked ✅ above), matching the site's own registry (`lib/calculators.ts`, the authoritative live count) exactly — even though a couple of these items collapse onto the same PaisaCalc page (Mortgage + Amortization both → Home Loan EMI; Salary + Take-Home-Paycheck both → In-hand Salary from CTC).
- **9 are US-specific with no clean Indian equivalent** (FHA/VA mortgage programs, Social Security, Roth IRA/IRA/RMD, Marriage Tax, Estate Tax, Boat Loan) — not worth porting.
- **1 is not applicable** (VAT — India uses GST, already covered).
- **7 were intentionally skipped**, each with reasoning inline above at its own numbered entry:
  - **Finance Calculator** and **Interest Rate Calculator** — generic "solve for any missing TVM variable" tools, a fundamentally different pick-what-to-solve-for UI than every fixed-inputs calculator on the site.
  - **Loan Calculator**, **Payment Calculator**, **Repayment Calculator** — generic versions of the Home/Car/Personal/Education loan EMI calculators already live.
  - **Currency Calculator** — needs live FX rates, which this static-export site has no server to fetch.
  - **Annuity Calculator** — its accumulation-phase math is identical to what SIP Returns and the Interest Calculator already do.
- **Fitness & Health, Math, and Other are a different product entirely** — building any of them would change what PaisaCalc *is*, not just add to what it does.
